# Architecture Portfolio

A personal **architecture portfolio website** showcasing design projects — private villas, resorts, clubs, and urban developments — built as a responsive static site.

## What it does

Presents an architect's portfolio with a visual gallery of completed projects, each with a cover image and photo slides. The site is live and deployed on Vercel.

## Live Demo

🌐 [architecture-portfolio-murex.vercel.app](https://architecture-portfolio-murex.vercel.app/)

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**

Open `index.html` directly in a browser, or deploy to any static hosting provider.
